# Week 5 worked examples

Each `examples/w5-NN/` folder holds the session's two worked demonstrations as runnable scripts plus a
README with the commands, the expected normal and failure results and the offline trace. Run the
scripts from the course `source/` folder (the "pack/repository root" in the book) in Git Bash or a
Unix shell. They prepare NEW directories (default under `/tmp`, or pass a path) and stop the host they
start on port 5055 when they finish. Stop any host you started yourself on 5055 first.

* W5.01–W5.05 use `assets/session-api` and the helpers in [`_lib/`](_lib/).
* W5.06–W5.10 use `assets/integrated-release` (`run.py`, `release.py`, `peer-change.py`).

Offline traces are supplied analysis, not execution evidence. Your own observations go in the lab's
`evidence.md`.
