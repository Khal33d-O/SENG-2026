# W3.05 worked examples

Run from a working copy of `../../labs/w3-05/assets` after `npm ci`. The complete sequence with recorded output is `../../labs/w3-05/demo-record.md`; the complete local PR example is `../../labs/w3-05/local-pr-example.md`.

- `W305_STATE=$(python3 review.py prepare demo)`, create `feature/familiar-fix`, add a detached review at `@base` (check fails), commit only `src/rules.ts`, `record` the proposal, switch the review to `@proposal`, `check` (passes) and `preserve`.

No live model, API key or account is used by any example.
