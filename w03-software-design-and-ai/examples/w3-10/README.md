# W3.10 demonstrations

The plain-JavaScript demonstration is `../../labs/w3-10/demo/` (`demo/browser/app.mjs`, `demo/browser/client.mjs`, `demo/supplied/handler.mjs`).

- From `labs/w3-10`: `make demo MODE=success` (or `python lab.py demo --mode success`), open http://127.0.0.1:4310; repeat with `MODE=validation` and `MODE=timeout`; stop the server and request again to see the unavailable message.

No live model, API key or account is used by any example.
