# W3.03 worked examples

The complete teaching example is `../../labs/w3-03/starter/demo.mjs` with `src/demo-red.ts`, `src/demo-green.ts` and `src/demo-refactor.ts`.

- From `labs/w3-03/starter`: `npm ci`, then `npm run demo:red` (fails: four moves, expected five, exit 1), `npm run demo:green`, `node regression.mjs demo-green`, `npm run demo:refactor`, `node regression.mjs demo-refactor`.
- Captured output for blocked environments: `../../labs/w3-03/captured-demo-output.md`.

No live model, API key or account is used by any example.
