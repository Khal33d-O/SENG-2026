# W1.02 document brief and rubric

**Brief.** Complete [`../evidence.md`](../evidence.md) outside your `practice` repository. Include concise command
excerpts that show the selected versions; avoid a transcript so long that a reviewer cannot locate the claim it supports.
State the checker result and any remaining failure honestly. Code and document evidence describe the same task;
neither substitutes for the other.

| Criterion | Meets | Not yet |
|---|---|---|
| Versions located | Names committed, indexed and working contents of `display.txt` with observations | Relies on "it passed" or memory |
| Commit decision | Prediction before the commit, supported by the cached diff; rejected alternative explains what it would select | Decision recorded only after the result |
| Recovery source | Chosen and rejected candidates identified by content, with identifiers from the learner's own log | Chooses by position (`HEAD~1`) or message |
| Bounded recovery | Shows recovered text, unchanged committed text and both drafts preserved | Clean status obtained by committing drafts |
| Remote claim | Distinguishes local HEAD, `origin/main` and the bare origin's actual value | Claims the commit was shared |
| Honesty and assistance | States checker result, captured vs live evidence, assistance | Missing or overstated |
